# MajFifty Robot

Versão do documento: 1.0

## Missão

Construir uma IDE Visual para Robótica Educacional moderna,
offline-first, open source e multiplataforma.

O projeto NÃO pretende ser um clone da Arduino IDE.

O Blockly é apenas uma das ferramentas da IDE.

A IDE deve evoluir para suportar:

• Arduino
• ESP8266
• ESP32
• Raspberry Pi Pico
• Simulação
• Plugins

Princípios

- Código limpo.
- Arquitetura modular.
- Offline First.
- Sem dependência de CDN.
- Código legível acima de código "inteligente".
- Sempre preservar compatibilidade.
